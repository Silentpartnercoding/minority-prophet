# Agent WEX Instagram A/B Test v1

## The question

Which message moves developers from an Instagram impression to a working Agent WEX node?

- **A — Collective learning:** An agent works. All agents learn. Every run makes agents smarter.
- **B — Avoid duplicated work:** Do not rediscover what another agent already learned. Reuse supported routes. Save compute.

Only the image and its embedded message change. Audience, placement, caption, CTA, landing page, schedule, and delivery budget remain identical.

## What counts as winning

The primary metric is successful node registrations per landing-page view. Install-command copies are a secondary intent signal. Click-through rate is diagnostic only.

Do not declare a winner until each arm has at least 30 successful node registrations and the difference is statistically supported. If it is not supported, report no winner.

## Before launch

1. Add UTM attribution to install-command copies and successful node registrations.
2. Set a fixed total budget, geography, audience, dates, and 50/50 split.
3. Obtain owner approval for publication and spend.
4. Do not edit either arm after launch.

This package prepares the experiment. It does not launch a campaign or authorize spending.
