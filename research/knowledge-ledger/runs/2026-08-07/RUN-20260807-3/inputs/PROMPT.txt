TWO REPAIRS

R5.1 — REGISTER THE RECEIPT OBJECT (its finding G2, the decisive one).

  R4 defined the canonical FORM (codec) and the digest SCOPE (which member is
  removed). It never defined the receipt OBJECT. canonicalForm.digestScope
  names covered members including `schema`, `reason` and `limits`, and the
  value of none of them is stated anywhere in v1.1.0, nor is the receipt's
  member list registered. A conforming codec cannot reproduce a digest when the
  bytes it must hash are unspecified.

  Concretely: the independent implementation's receipt carries `receiptVersion`;
  I checked the reference's and its members are exactly
  claim, conclusion, contentDigest, evidence, limits, reason, schema, search,
  transactionId — no receiptVersion. Two conformant codecs, two member sets,
  two digests.

  Register the receipt object: the complete member list, the type of each
  member, and for `schema`, `reason` and `limits` the exact value or the rule
  that derives it. Anything a digest covers must be specified or excluded from
  the digest — pick one deliberately and say which.

R5.2 — DEFINE THE SIGN OF `margin` (its finding G1).

  The reference computes margin as an absolute value: I verified zero negative
  margins across all 110,840 receipts. The independent implementation computes
  it signed: 38,760 receipts carry a negative margin and therefore have no
  defined canonical form, because canonicalForm.numbers asserts receipts contain
  only non-negative integers. That assertion is true under one reading and false
  under the other, and v1.1.0 never says which.

  This is an owner-style decision like the tie rule, so state it as a decision
  rather than a derivation. Absolute is what the reference already does and
  makes the numbers clause true with no other change; signed carries more
  information (which side leads) and would require canonicalForm.numbers to
  define negative-integer serialisation. Recommend one, record the rejected
  reading, and note that the independent implementation chose signed and its
  choice was defensible.
