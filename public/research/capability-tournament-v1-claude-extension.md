# Capability Tournament v1 — Claude extension preregistration

Status: frozen before any Claude extension execution.

Frozen: 2026-08-11 (America/Los_Angeles)

## Purpose

Extend the already frozen Capability Tournament v1 to Anthropic Claude without
altering, pooling away, or rerunning the initial GPT/Codex grid. The extension
answers the same bounded question: can a model recover the frozen
distinct-origin dispositions from the same complete lineage packets by
reasoning alone or with self-chosen tools?

This remains a finite lineage-aggregation contest. It is not a test of ultimate
truth discovery, root legitimacy, or real-world source independence.

## Frozen inheritance

The extension inherits without modification:

- generator seed `2026081000`;
- 8 cases, 16 propositions per case, and 128 scored dispositions per lane;
- manifest hash
  `sha256:e65d843669b1a0ead2a468ed8f05a44f3d74cf6e8184c05d2f697e427a8ec4ff`;
- the exact serialized `public_packet` bytes, prompt body, response schema,
  hidden reference, scoring rule, and failure treatment from Capability
  Tournament v1;
- the A reasoning-only and B tools-available lane definitions;
- the already recorded canonical C and conventional fixed-method results.

Claude receives no hidden key, root map, root count, precomputed root IDs,
Minority Prophet output, or result from another contestant.

## Claude grid

The locally authenticated Claude subscription CLI will run:

- `opus`;
- `sonnet`;
- `haiku`.

The resolved canonical model identifier reported by the CLI is retained with
each trial. Each alias runs all eight cases in both lanes at medium effort.
Calls are ephemeral, session persistence is disabled, user/project
customizations are disabled, and no MCP servers or browser integration are
available.

### A — reasoning only

All built-in tools are disabled. Any observed tool request invalidates the
trial and scores it as incorrect.

### B — tools available

Claude may choose Bash, file operations inside its isolated temporary
workspace, Web Search, or Web Fetch. `case.json` is an exact copy of the inline
packet. Tool requests and commands are retained for audit. Claude is not told
about Minority Prophet and is not instructed to trace, collapse, cluster, or
count roots.

## Outcomes and reporting

Report, per resolved model and lane:

- correct dispositions out of 128;
- exact cases out of 8;
- elapsed wall time;
- input, output, cache-read, and cache-creation tokens when reported;
- tool request count and types;
- the CLI's provider-reported cost estimate, clearly distinguished from an
  actual subscription bill;
- failures and policy violations, retained and counted incorrect.

Claude results will be labeled an extension. They may be displayed beside the
initial GPT grid when the identical manifest, packets, lanes, and scoring rule
are explicit; they may not be described as if they were part of the initial
model grid or as establishing stable provider rankings from one replicate.
