# Experiments

This directory contains protocols, runners, fixtures, and experiment-local
notes. Presence here does not make an experiment canonical.

## Main tracks

- `EXPERIMENT-001.md` and `EXPERIMENT-002-PREREGISTRATION.md` — early benchmark
  and resolved-weather work.
- `lir1/` through `lir4/` — lineage-inference boundary series.
- `heo1/`, `hes1/`, `hgd1/`, `hgd2/`, and `hvi1/` — focused evidence,
  dependency, and verification experiments.
- `eaa-p5/` — unified dependence-auditor protocol material.
- `asymmetric-claims/` — counterexamples for claim shapes where ordinary voting
  is inappropriate.
- `replications/` — replication runners and fixtures.

## How to determine status

Do not infer status from a folder name or result file. Follow the experiment ID
through:

1. [`research/records/`](../research/records/)
2. [`CANONICAL-RECORDS.md`](../CANONICAL-RECORDS.md)
3. [`EVIDENCE-ALIGNMENT.md`](../EVIDENCE-ALIGNMENT.md)
4. the corresponding package under [`results/`](../results/)

Preregistrations and frozen implementations may be content-bound. Do not edit
them merely to improve presentation; add navigation or a new version instead.
