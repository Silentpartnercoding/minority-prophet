# AWE commercial renderer

Code-rendered 15-second vertical commercial for Agent Witness Exchange.

The spot uses a synthetic product fixture. It does not imply a live agent
network, production scale, or a guaranteed route. A Working Route appears only
after two independent successful outcome roots support the same bounded route.

```bash
npm install
npm run render
```

Outputs:

- `../../public/awe-commercial-v2.mp4`
- `../../public/awe-commercial-v2-poster.jpg`

The MP4 is 1080×1920, 30 fps, H.264 High Level 4.1, muted, and suitable for
an Instagram Reel or an inline `playsInline` landing-page video. The storyboard
shows one continuous synthetic task: fail, contribute, ask, verify, pass Gate,
and resume.
