# LIR-4 sealed PHEME holdout

The public inventory binds 400 final-unused PHEME cases containing 5,000 claims.
It excludes all 1,449 cases used by LIR-1 through LIR-3. Tweet content,
identities, and normalized rows remain local; hashes bind the private input.

Only one selected case contains multiple recorded roots. The preregistered
cross-root safety diagnostic is therefore known to be underpowered before
outcome scoring and cannot support a general resistance claim.
