# LIR-2 development selection

Threshold `0.75` was selected under the preregistered precision constraint. On
the 48 open LIR-1E cases it achieved root-pair precision `1.0`, recall `0.9907`,
100% inferred answer coverage, 100% accuracy, and zero false reversals.

These are development values and are not evidence for the LIR-2 claim. The
threshold is frozen before generating the new 36-case holdout.
