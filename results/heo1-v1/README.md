HEO-1 tested whether supported derivation lineage can prevent separate
controllers from multiplying one underlying observation into apparent
independent evidence.

All six frozen hypotheses passed across 5,000 base worlds and 50,000 matched
representations. Byte copies, paraphrases, translations, summaries, model
transformations, and a 32-item mixed transformation set added zero
evidence-origin roots. Unknown and forged origins escalated in every world,
while supported separate origins were retained completely.

The origin-aware method held decision error at 3.54% across transformed-copy
conditions. Controller counting treated 32 transformed descendants as 32 roots
and reached 75.32% error. The paired error advantage was 44.0–45.7 percentage
points under the frozen model.

The genuine-origin condition preserves the boundary: eight separately captured
but identically adverse observations remained eight roots and produced 75.32%
error. Provenance establishes recorded origin structure, not truth.
